## 8. Masalah atau Risiko yang Tersisa

1. **Sisa `19` Vulnerability Dev/Build-Time (`0` di App Runtime):**
   - `1` Critical (`@babel/traverse@7.21.5`) + `1` Low (`@babel/core@7.21.8`) + `1` High (`semver@6.3.0`/`5.7.1`) bertahan karena `npm install` mempertahankan entry lockfile lama (`@babel/core@7.21.8` dan `less@4.1.3`) yang cocok dengan peer range `^7.0.0` / `*`.
   - `7` CVE berasal dari `eslint@8.40.0` (yang juga masih berada di `dependencies` dan belum memiliki konfigurasi `.eslintrc*`).
   - `6` CVE berasal dari `tailwindcss@3.3.2` + `1` dari `postcss` (`source-map-js`), yang saat ini belum terkonfigurasi.
   - `2` CVE (`vite@5.4.21` High + `esbuild@0.21.5` Moderate) menunggu evaluasi terpisah untuk upgrade mayor Vite.
2. **Konfigurasi Build & CSS yang Sengaja Belum Diubah:**
   - Directive `@tailwind`/`@apply` di `global.css` masih mentah di hasil build, `index.html` belum memiliki DOCTYPE/head lengkap, `tsconfig.json` masih menargetkan `es5` dan belum mencakup `src/services/`, dan Vite masih memunculkan peringatan CJS Node API (`"type": "module"` belum ditambahkan).
3. **Prasyarat Native Windows (`MSVC`):**
   - Visual Studio C++ Build Tools + Windows SDK masih belum terpasang sejak fase B1.
4. **Working Tree Belum Di-commit:**
   - Perubahan `package.json`, `package-lock.json`, serta laporan B2/B3-A/B3-B menunggu review dan persetujuan pemilik proyek sebelum di-commit atau dilanjutkan ke fase berikutnya.
