## 1. Summary of Changes

Pekerjaan `WP-10 (Rust)` dan `WP-07` telah diimplementasikan untuk mengganti pembukaan URL berbasis shell Windows (`cmd.exe /C start`) dengan mekanisme native yang dimediasi Rust melalui `tauri-plugin-opener`:

1. **Penambahan Dependensi Rust Terkunci (`WP-10 Rust`):** Menambahkan `tauri-plugin-opener = "2"` (terkunci aman di `2.5.5`) dan `url = "2"` (sudah terkunci di `2.5.8`) ke [`src-tauri/Cargo.toml`](src-tauri/Cargo.toml) tanpa mengubah versi `tauri 2.11.5` maupun plugin Tauri yang sudah terpasang.
2. **Registrasi Plugin & Penghapusan `cmd /C start` (`WP-07`):** Mendaftarkan `tauri_plugin_opener::init()` pada builder di [`src-tauri/src/lib.rs`](src-tauri/src/lib.rs), serta mengganti implementasi `open_external_url` dengan validasi URL terstruktur (`url::Url` + `ALLOWED_EXTERNAL_URLS = &[]`) yang diteruskan ke `OpenerExt` (`app.opener().open_url(...)`).
3. **Least-Privilege Frontend & Preserving `WP-05`:** Tidak menambah permission `opener:*` ke [`src-tauri/capabilities/default.json`](src-tauri/capabilities/default.json), tidak mengubah `src/App.tsx` untuk `C-B-B-2` (kompatibel langsung dengan command `open_external_url`), dan seluruh perubahan `WP-05` (`expand_main_window` `LogicalSize` + `show()`/`set_focus()`) tetap utuh.

## 3. Implementation Summary

- **Plugin Registration ([`src-tauri/src/lib.rs`](src-tauri/src/lib.rs#L193-L195)):**
  `.plugin(tauri_plugin_opener::init())` didaftarkan pada `tauri::Builder::default()` bersama `tauri_plugin_process::init()` dan `tauri_plugin_updater::Builder::new().build()`.
- **Strict URL Allowlist & Parser (`validate_external_url` & `ALLOWED_EXTERNAL_URLS`):**
  1. `const ALLOWED_EXTERNAL_URLS: &[&str] = &[];` dibiarkan kosong sesuai keputusan `D-8` (menolak seluruh URL eksternal sampai URL resmi StockStudio Pro ditetapkan).
  2. `validate_external_url_with_allowlist(raw_url: &str, allowlist: &[&str]) -> Result<url::Url, String>`:
     - Menolak string kosong atau input dengan spasi di awal/akhir (`raw_url != raw_url.trim()`).
     - Mem-parse dengan `url::Url::parse(raw_url)`.
     - Mewajibkan `parsed.scheme() == "https"`.
     - Mewajibkan `parsed.username().is_empty()` dan `parsed.password().is_none()`.
     - Mewajibkan `parsed.host_str().is_some()`.
     - Mencocokkan persis terhadap URL allowlist yang juga diparse via `url::Url::parse(allowed)` (`allowed_url == parsed && allowed_url.as_str() == parsed.as_str()`).
- **Safe Native Execution (`open_external_url`):**
  - Menjalankan `let validated = validate_external_url(&url)?;` sebelum memanggil `app.opener().open_url(validated.as_str(), None::<&str>).map_err(|e| e.to_string())`.
  - Menghapus total `std::process::Command::new("cmd")`, argumen `"/C", "start"`, dan string URL toko Flowpilot lama.

## 6. Limitations & Unresolved Items

1. **Allowlist Eksternal Sengaja Kosong (`ALLOWED_EXTERNAL_URLS = &[]`):** Saat ini pemanggilan `open_external_url` menolak semua URL secara aman sesuai kebijakan `D-8` sampai URL checkout / komunitas resmi StockStudio Pro ditetapkan dan disetujui. Akibatnya, eksekusi nyata membuka browser OS melalui `OpenerExt` belum dijalankan pada URL produksi.
2. **Pekerjaan Selanjutnya Masih Menunggu Tahap Berikutnya:** `WP-08` (WebView navigation allowlist & lifecycle/mutex fixes di `webview_manager.rs` / `FlowShell`), `WP-06` (self-hosted font & CSP ketat), `WP-09` (atomic persistence & bug akun), `WP-10` npm opsional, serta License API (`Fase D`) dan Updater Keys (`Fase E`) sengaja tidak diubah pada tugas ini.
