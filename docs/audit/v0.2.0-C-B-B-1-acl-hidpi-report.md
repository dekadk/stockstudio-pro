## 3. Implementation Details

### 3.1 Rust Backend (`src-tauri/src/lib.rs`)
- **Clamping & Logika HiDPI (`compute_expanded_logical_bounds`):**
  - Target default: `1280.0 Ã— 800.0` logical; minimum default: `1000.0 Ã— 700.0` logical.
  - Mengambil `window.current_monitor()` (fallback ke `window.primary_monitor()` jika `None`), memeriksa `scale_factor.is_finite() && scale_factor > 0.0`, lalu menghitung area kerja logis usable `(work_area.width / scale_factor, work_area.height / scale_factor)`.
  - Membatasi ukuran target agar tidak melebihi area kerja usable (`EXPANDED_TARGET_*.min(usable_*)`), lalu menjamin `min_width <= target_width` dan `min_height <= target_height` (`EXPANDED_MIN_*.min(target_*)`).
- **Urutan Kontrol Jendela & Propagasi Error (`expand_main_window`):**
  1. `window.set_resizable(true)`
  2. `window.set_min_size(Some(tauri::Size::Logical(min_size)))`
  3. `window.set_size(tauri::Size::Logical(target_size))`
  4. `window.center()`
  5. `window.show()`
  6. `window.set_focus()`
  - Seluruh panggilan memetakan error via `.map_err(|e| e.to_string())?` sehingga kegagalan tidak ditelan diam-diam. Registrasi `expand_main_window` pada `tauri::generate_handler!` dan seluruh command lainnya (`open_external_url`, Google Flow WebView, license, accounts) tetap utuh.

### 3.2 Frontend (`src/App.tsx`)
- Menghapus import `@tauri-apps/api/window` (`getCurrentWindow`) dan `@tauri-apps/api/dpi` (`PhysicalSize`).
- Baik efek validasi lisensi startup maupun handler `activateLicense` tetap memanggil `await invoke("expand_main_window")` tanpa memanggil `.show()` / `.setFocus()` dari sisi JavaScript.

### 3.3 Capabilities (`src-tauri/capabilities/default.json`)
- Tetap minimal: `"windows": ["main"]` dan `["core:default", "updater:default", "process:allow-restart"]` (`core:window:allow-show`, `core:window:allow-set-focus`, maupun `opener:*` tidak ditambahkan).
