## 4. Missing Prerequisites & Manual Installation Instructions

### Missing Components
1. **Microsoft Visual Studio C++ Build Tools (MSVC v143 x64/x86 Linker & Compiler):** `cl.exe`, `link.exe`, `vswhere.exe` missing.
2. **Windows 10/11 SDK:** Header and import libraries (`Windows Kits\10\Include`, `Windows Kits\10\Lib`) required by `tauri`, `windows-sys`, `webview2-com`, and `keyring` (`windows-native`).

### Minimal Recommended Installation Steps (No Unrelated Workloads)

**Option A — Official GUI Installer (Recommended):**
1. Download the official **Microsoft Visual Studio Build Tools** bootstrapper directly from Microsoft (the same official link reported by `tauri info`):  
   `https://aka.ms/vs/17/release/vs_BuildTools.exe`  
   *(or via https://visualstudio.microsoft.com/visual-cpp-build-tools/)*
2. Run `vs_BuildTools.exe` as **Administrator**.
3. On the **Workloads** tab, select **only**:
   - **Desktop development with C++** (`Microsoft.VisualStudio.Workload.VCTools`)
4. In the right-hand **Installation details** panel, ensure the default recommended native Windows components remain checked:
   - **MSVC v143 - VS 2022 C++ x64/x86 build tools**
   - **Windows 11 SDK** (or **Windows 10 SDK**)
   - Do **not** add unrelated workloads (.NET, Python, UWP, Node.js, or full IDE components).
5. Complete installation, then **restart your terminal/IDE** (so both Visual Studio Build Tools and `%USERPROFILE%\.cargo\bin` are picked up on `PATH`).

**Option B — Minimal Unattended CLI Install (Run in an Elevated / Administrator PowerShell):**
```powershell
$vs = Join-Path $env:TEMP "vs_BuildTools.exe"
Invoke-WebRequest -Uri "https://aka.ms/vs/17/release/vs_BuildTools.exe" -OutFile $vs -UseBasicParsing
Start-Process -FilePath $vs -ArgumentList "--quiet", "--wait", "--norestart", "--nocache", "--add", "Microsoft.VisualStudio.Workload.VCTools", "--includeRecommended" -Wait
Remove-Item $vs -Force -ErrorAction SilentlyContinue
```

**Post-Install Verification (Run in a freshly opened PowerShell at the project root):**
```powershell
rustc --version
cargo --version
& "${env:ProgramFiles(x86)}\Microsoft Visual Studio\Installer\vswhere.exe" -latest -products * -requires Microsoft.VisualStudio.Component.VC.Tools.x86.x64 -property installationPath
npx --no-install tauri info
```
Expect `✔` next to Visual Studio Build Tools / MSVC and Windows SDK in `tauri info` before proceeding to baseline Rust builds.
