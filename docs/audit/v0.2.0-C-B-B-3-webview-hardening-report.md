## 3. Navigation Allowlist
`is_allowed_navigation_url(url: &url::Url) -> bool` menerima URL hanya jika:
1. Scheme tepat `https`.
2. Tanpa username dan password.
3. Host bertipe domain (IP literal dan host kosong ditolak), dinormalisasi lowercase, trailing dot dibuang.
4. Host sama persis dengan entri allowlist, atau subdomain dengan batas titik (`strip_suffix` + prefix berakhir `.`). Tidak ada `contains()` atau substring.

`on_new_window` tetap `Deny`. Navigasi yang ditolak dicatat hanya pada build debug (`cfg!(debug_assertions)`) dengan format `blocked navigation scheme=<scheme> host=<host>`; path, query, dan kredensial tidak pernah dicatat.

## 5. Visible State dan Mutex
- `close()`: `state.visible = false` kini hanya dijalankan ketika `should_mark_hidden(active, requested)` bernilai true (ID diminta sama dengan ID aktif, atau tanpa ID). Menutup ID non-aktif atau saat tidak ada WebView aktif tidak mengubah `visible`.
- `resize()`: mengambil `state.operation` di awal, sebelum membaca `active_account_id`. Urutan kunci (`operation` lalu `active_account_id`) sama dengan `open()`/`close()`/`remove()`, sehingga tidak ada kunci ganda atau inversi urutan. Perilaku resize lainnya tidak berubah.

## 6. FlowShell

## 8. Temuan dan Keterbatasan
1. **Login Google berisiko terblokir.** Allowlist hanya berisi `flow.google` dan `labs.google` sesuai instruksi untuk tidak menambah domain tanpa bukti. Google Sign-In umumnya melibatkan host lain (mis. `accounts.google.com`), yang kini ditolak. Saya tidak menjalankan alur login nyata, jadi daftar host tambahan belum terbukti. Langkah berikutnya: jalankan `npm run tauri dev`, coba login, ambil host dari log `blocked navigation ...`, lalu tambahkan hanya host yang terbukti diperlukan ke `ALLOWED_NAVIGATION_HOSTS` beserta test.
2. `about:blank` ditolak. Belum diverifikasi apakah WebView2 memerlukannya saat inisialisasi.
3. `on_new_window` tetap `Deny`, sehingga popup OAuth (jika dipakai Google Flow) akan gagal.
4. Tidak ada pengujian runtime interaktif (login, pergantian akun, `__TAURI_INTERNALS__` di child WebView) pada tugas ini.
5. WP-06 (CSP/font) dan WP-09 belum dikerjakan.
