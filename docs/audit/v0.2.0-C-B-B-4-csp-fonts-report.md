## 7. Alasan Setiap Directive CSP

| Directive | Production (`csp`) | Development (`devCsp`) | Alasan Teknis & Keamanan |
|---|---|---|---|
| `default-src` | `'self'` | `'self'` | Fallback ketat yang membatasi seluruh resource ke origin bundel aplikasi Tauri sendiri. |
| `script-src` | `'self'` | `'self' 'unsafe-inline' http://localhost:5173` | Di produksi hanya mengizinkan bundle JS lokal dan Tauri nonce injection (tanpa `'unsafe-inline'` atau `'unsafe-eval'`). Di mode dev mengizinkan Vite preamble & HMR dari `http://localhost:5173`. |
| `style-src` | `'self'` | `'self' 'unsafe-inline' http://localhost:5173` | Di produksi hanya memuat bundle CSS lokal (`dist/assets/index-*.css`). Di mode dev mengizinkan injeksi `<style>` Vite HMR. |
| `font-src` | `'self'` | `'self' http://localhost:5173` | Mengizinkan pemuatan 4 file `.woff2` `Plus Jakarta Sans` yang dibundel secara lokal tanpa akses ke `fonts.gstatic.com`. |
| `img-src` | `'self' data:` | `'self' data: http://localhost:5173` | Mengizinkan aset gambar/SVG lokal (`'self'`) serta URI `data:image/...` untuk fitur upload avatar profil pengguna. |
| `connect-src` | `ipc: http://ipc.localhost` | `ipc: http://ipc.localhost http://localhost:5173 ws://localhost:5173` | Mengizinkan komunikasi IPC Tauri v2 (`invoke()`) di Windows WebView2 (`ipc:` & `http://ipc.localhost`), sementara seluruh panggilan HTTP lisensi dilakukan di sisi Rust (`reqwest`). Mode dev menambahkan HTTP & WebSocket HMR Vite (`localhost:5173`). |
| `object-src` | `'none'` | `'none'` | Memblokir penuh plugin legacy (`<object>`, `<embed>`, `<applet>`). |
| `base-uri` | `'self'` | `'self'` | Mencegah serangan manipulasi tag `<base>`. |
| `form-action` | `'none'` | `'none'` | Aplikasi tidak menggunakan pengiriman `<form>` HTML tradisional; seluruh aksi ditangani melalui state React dan Tauri IPC. |
| `frame-ancestors` | `'none'` | `'none'` | Mencegah pembingkaian (*framing/clickjacking*) dokumen shell utama. |

## 8. Analisis Kompatibilitas Avatar `data:` dan `DragPreview`

1. **Avatar Profil Pengguna (`FileReader.readAsDataURL`):**
   - Pada `src/App.tsx` (komponen `Settings`, fungsi `handleAvatarChange`), file gambar yang dipilih pengguna dibaca menggunakan `FileReader.readAsDataURL(file)` yang menghasilkan string `data:image/...;base64,...`, disimpan di `localStorage` (`stockstudio_profile`), dan dirender oleh `<img src={profile.avatar} />` di `Settings` serta `Sidebar`.
   - Dengan menyertakan `data:` secara eksplisit pada `img-src 'self' data:`, avatar profil dirender dengan aman tanpa membuka akses gambar ke domain eksternal (`https:`).
2. **Komponen `DragPreview` (`style={{ transform: ... }}`) & Kompatibilitas `style-src 'self'`:**
   - Pada `src/App.tsx` (komponen `DragPreview`), posisi kustom saat drag akun diatur melalui prop React `style={{ transform: \`translate3d(${dragState.x - 100}px, ${dragState.y - 20}px, 0)\` }}`.
   - Di seluruh codebase `src/`, tidak ditemukan penggunaan `setAttribute("style", ...)`, tag `<style>` inline di HTML (`index.html`), maupun `innerHTML` dengan atribut `style="..."`.
   - React 18 menerapkan prop `style={{ ... }}` melalui API objek CSSOM (`element.style.transform = ...`), bukan melalui parser atribut string HTML, sehingga kompatibel dengan `style-src 'self'` di produksi tanpa memerlukan `'unsafe-inline'`.
