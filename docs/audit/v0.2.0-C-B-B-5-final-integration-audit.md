## 2. Ringkasan Hasil Pemeriksaan Setiap Work Package

### A. `WP-05`: Tauri Window ACL & HiDPI Hardening (`C-B-B-1`) — **VERIFIED**
1. **`LogicalSize` & Monitor Clamping:**
   - Pada `src-tauri/src/lib.rs:126-189`, `expand_main_window` menggunakan `compute_expanded_logical_bounds(usable_logical_area)` dengan target default `LogicalSize(1280.0, 800.0)` dan minimum default `LogicalSize(1000.0, 700.0)`.
   - Dimensi dihitung dari `monitor.work_area().size` dibagi `monitor.scale_factor()` (dengan fallback `current_monitor()` → `primary_monitor()`), sehingga pada layar laptop HiDPI 125%/150% ukuran target dan minimum di-clamp agar tidak melebihi work area layar.
2. **`show()` dan `set_focus()` di Sisi Rust:**
   - `window.show()` dan `window.set_focus()` dipanggil langsung di dalam `expand_main_window` (`src-tauri/src/lib.rs:186-187`) dengan propagasi error `Result<(), String>`.
   - Di `src/App.tsx:93` dan `src/App.tsx:304`, frontend hanya memanggil `await invoke("expand_main_window")` tanpa mengimpor `@tauri-apps/api/window` (`getCurrentWindow`) atau `@tauri-apps/api/dpi` (`PhysicalSize`).
3. **Least-Privilege Capabilities:**
   - `src-tauri/capabilities/default.json` tidak berubah dan hanya memberikan `["core:default", "updater:default", "process:allow-restart"]` untuk window `["main"]`. Tidak ada penambahan `core:window:allow-show`, `core:window:allow-set-focus`, `core:window:allow-set-size`, atau permission window berlebih lainnya.

### B. `WP-10 Rust + WP-07`: External Opener Hardening (`C-B-B-2`) — **VERIFIED**
1. **Penghapusan `cmd.exe /C start`:**
   - Hasil pencarian `cmd /C`, `cmd.exe`, dan `Command::new` di seluruh `src/` dan `src-tauri/` adalah **`0` kemunculan**.
2. **Registrasi Opener Plugin & Versi Tauri:**
   - `tauri_plugin_opener::init()` terdaftar pada `tauri::Builder::default()` di `src-tauri/src/lib.rs:194`.
   - `tauri` tetap terkunci pada versi **`2.11.5`** (`tauri-plugin-opener v2.5.5`, `url v2.5.8`).
   - Tidak ada paket JS `@tauri-apps/plugin-opener` yang dipasang dan tidak ada permission `opener:default` / `opener:allow-open-url` yang diekspos ke frontend di `src-tauri/capabilities/default.json`.
3. **Validasi URL Ketat & Allowlist Kosong di Sisi Rust:**
   - `ALLOWED_EXTERNAL_URLS: &[&str] = &[]` pada `src-tauri/src/lib.rs:84`.
   - `validate_external_url_with_allowlist` (`src-tauri/src/lib.rs:86-112`) memvalidasi input non-kosong tanpa leading/trailing whitespace, parsing `url::Url::parse`, skema wajib `"https"`, tanpa `username`/`password`, memiliki `host_str()`, dan wajib cocok penuh (`allowed_url == parsed && allowed_url.as_str() == parsed.as_str()`) dengan entri allowlist sebelum diteruskan ke `app.opener().open_url(validated.as_str(), None::<&str>)`.

### C. `WP-08`: Child WebView Isolation & Hardening (`C-B-B-3`) — **VERIFIED**
1. **Navigation Allowlist Berbasis Hostname Ketat:**
   - Pada `src-tauri/src/webview_manager.rs:17-40`, `ALLOWED_NAVIGATION_HOSTS` hanya berisi `&["flow.google", "labs.google"]`.
   - `is_allowed_navigation_url` memeriksa `url.scheme() == "https"`, menolak kredensial (`username`/`password`), mengekstrak `url::Host::Domain(domain)` (menolak IP literal IPv4/IPv6), menormalisasi lowercase dan trailing dot, serta hanya mengizinkan exact match (`host == *allowed`) atau subdomain berbatas titik (`prefix.ends_with('.') && prefix.len() > 1`).
   - Pada `on_navigation` (`src-tauri/src/webview_manager.rs:205-216`), navigasi yang ditolak hanya dicatat pada mode debug (`cfg!(debug_assertions)`) dengan mencetak `scheme` dan `host` saja (tanpa path, query string, atau kredensial).
2. **Isolasi Child WebView:**
   - `on_new_window` (`src-tauri/src/webview_manager.rs:217`) tetap mengembalikan `tauri::webview::NewWindowResponse::Deny`.
   - `src-tauri/capabilities/default.json` tetap dibatasi hanya pada `"windows": ["main"]`, sehingga child WebView `google-flow-{account_id}` tidak memiliki akses ke Tauri IPC internals.
3. **Perbaikan State `close()` dan Mutex `resize()`:**
   - `close()` (`src-tauri/src/webview_manager.rs:240-264`) menggunakan helper `should_mark_hidden(active_account.as_deref(), account_id.as_deref())` sehingga `visible` hanya diubah menjadi `false` dan webview hanya di-`hide()` apabila akun yang ditutup memang sedang aktif (atau `account_id == None`).
   - `resize()` (`src-tauri/src/webview_manager.rs:266-297`) mengakuisisi `state.operation.lock()` sebelum memeriksa `active_account_id` dan mengubah posisi/ukuran WebView, mencegah race condition dengan `open()`, `close()`, dan `remove()`.
4. **Perbaikan Lifecycle `FlowShell`:**
   - Pada `src/App.tsx:1068-1110`, `FlowShell` me-reset `setStatus("Loading Google Flow...")` setiap kali `account.id` berubah, menjaga flag `cancelled` agar penyelesaian async dari akun lama tidak menimpa state akun baru, dan menyertakan `account.id` pada dependency array `useEffect` `ResizeObserver` (`[account.id, navigatorOpen, fullView]`).

### D. `WP-06`: CSP Hardening & Self-hosted Fonts (`C-B-B-4`) — **VERIFIED**
1. **Self-hosted Font `Plus Jakarta Sans` & Lisensi OFL:**

## 5. Daftar Runtime Test yang Masih Tertunda (Setelah License API Tersedia)

Karena endpoint License API StockStudio Pro belum tersedia dan license gate tidak boleh di-bypass, pengujian runtime pasca-aktivasi berikut tercatat sebagai **tertunda (*pending runtime verification*)** dan belum diklaim lulus:

1. **Verifikasi Runtime `WP-05` (Transisi Ukuran Window & HiDPI):**
   - Menguji aktivasi lisensi valid dan memverifikasi bahwa `expand_main_window` mengubah ukuran jendela dari `540x620` ke `1280x800` (logical) dengan `minWidth: 1000`, `minHeight: 700`, memusatkan jendela, serta menampilkan dan memfokuskan jendela pada monitor scaling `100%`, `125%`, dan `150%`.
2. **Verifikasi Runtime `WP-06` (CSP Runtime, Font Offline, Avatar `data:`, & Drag-and-Drop):**
   - Memverifikasi di DevTools WebView2 produksi bahwa tidak ada pelanggaran CSP (`SecurityPolicyViolationEvent`) pada halaman aktivasi maupun seluruh tab dashboard (`Accounts`, `Favorites`, `License`, `Updates`, `Info`, `Settings`, `FlowShell`).
   - Memverifikasi rendering keempat bobot font `Plus Jakarta Sans` (`400`, `500`, `600`, `700`) saat kondisi perangkat *offline* (tanpa koneksi internet).
   - Menguji upload foto profil di tab `Settings` (`FileReader.readAsDataURL` → `<img src="data:image/...">`) di bawah policy `img-src 'self' data:`.
   - Menguji interaksi *pointer drag-and-drop* kartu akun (`DragPreview` dengan `style={{ transform: ... }}`) di bawah policy `style-src 'self'`.
3. **Verifikasi Runtime `WP-07` (External Opener):**
   - Memverifikasi bahwa pemanggilan `invoke("open_external_url", ...)` dari DevTools console ditolak oleh Rust selama `ALLOWED_EXTERNAL_URLS` kosong, dan memverifikasi pembukaan browser default OS ketika URL resmi pembelian/Telegram nantinya ditambahkan ke allowlist.
4. **Verifikasi Runtime `WP-08` (Google Flow Child WebView & Google Sign-In):**
   - Membuka akun Google Flow di `FlowShell`, menjalankan alur Google Sign-In nyata, dan mengamati log `[stockstudio-webview] blocked navigation scheme=... host=...` pada mode debug (`npm run tauri dev`) untuk mengidentifikasi hostname OAuth/aset Google yang sah (seperti `accounts.google.com` dll.) yang perlu ditambahkan berdasarkan bukti runtime.
   - Menguji perpindahan cepat antar-akun melalui mini-navigator serta resize/fullscreen `FlowShell` untuk memverifikasi sinkronisasi posisi child WebView dan isolasi sesi per akun.
