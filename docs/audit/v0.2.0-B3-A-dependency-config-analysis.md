## Executive Highlights

1. **Zero Production Runtime npm Vulnerabilities:** Out of **90** reported `npm audit` vulnerabilities (`18` Critical, `35` High, `29` Moderate, `8` Low), **0** touch any package actually used at runtime (`react`, `react-dom`, `@tauri-apps/api`, `@tauri-apps/plugin-updater`, `@tauri-apps/plugin-process`).
2. **Only 2 Dev/Build Advisories Affect Active Tooling:** **88 of 90** vulnerabilities (`97.8%`) live exclusively inside unused template packages (Storybook, Next.js, Cypress, Commitizen, ESLint, Webpack loaders) or unreferenced legacy copies. Once unused packages are removed, only **2 dev/build-time advisories** remain (`vite@5.4.21` High and its nested `esbuild@0.21.5` Moderate).
3. **Empirically Confirmed Unprocessed Tailwind Directives:** Running `vite build` to a temporary output folder confirmed raw `@tailwind` and `@apply` statements (referencing missing theme tokens such as `noble-black-700` and `stem-green-500`) ship verbatim in the built CSS (`19.34 kB`) because no `tailwind.config.*` or `postcss.config.*` exists.
4. **Rust `reqwest` Major-Version Split:** `src-tauri/Cargo.toml` pulls `reqwest 0.12.28` directly while `tauri 2.11.5` and `tauri-plugin-updater 2.10.1` pull `reqwest 0.13.4`, compiling two HTTP/TLS stacks in `Cargo.lock`.
5. **Tauri Bundler Misdetection:** `npx tauri info` reports `bundler: Webpack` due to unused Webpack/Next/Storybook dependencies in `package.json`, even though the active frontend bundler is Vite `5.4.21`.
