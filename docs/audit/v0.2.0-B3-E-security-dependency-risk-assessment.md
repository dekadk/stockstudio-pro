## Executive Summary

Audit read-only terhadap repositori saat ini menunjukkan profil risiko dua lapis: **risiko produksi dari dependensi npm sangat rendah (`0` CVE di runtime aplikasi)**, namun **risiko arsitektur, supply-chain updater, keamanan WebView/CSP, kontrak lisensi, dan identitas aplikasi masih berada pada level CRITICAL/HIGH** karena warisan Flowpilot `v1.2.0`.

- **npm Security (`19` total CVE, `exit code: 1`):** `0` CVE pada dependensi runtime aplikasi (`react`, `react-dom`, `@tauri-apps/*`). Seluruh `19` CVE (`1` Critical, `10` High, `6` Moderate, `2` Low) hanya berada di tooling build/dev (`vite`, `esbuild`, sisa peer lockfile `@babel/traverse`/`@babel/core`/`semver`, `tailwindcss`/`postcss`, dan `eslint`).
- **Rust Dependencies (`cargo tree -d --locked`):** `0` warning kompilasi dan `reqwest` ganda (`0.12.28` vs `0.13.4`) yang menyebabkan kompilasi dua stack HTTP dan dua verifikator TLS (`webpki-roots` vs `rustls-platform-verifier`). `cargo-audit` tidak tersedia secara lokal sehingga pemindaian CVE crate Rust belum berjalan.
- **Tauri Security & ACL Bug Nyata:** `"csp": null` menonaktifkan proteksi XSS pada jendela utama yang memegang seluruh 13 IPC command; WebView anak mengizinkan seluruh domain `https://`; `open_external_url` memanggil `cmd.exe /C start`; serta pemeriksaan skema ACL hasil build (`src-tauri/gen/schemas/acl-manifests.json`) membuktikan `core:window:default` **tidak mencakup `allow-show` maupun `allow-set-focus`** yang dipanggil di `src/App.tsx:122,333`.
- **License & Auto-Updater Blockers:** Aplikasi masih terikat ke Cloudflare Worker Flowpilot (`flowpilot-license-server.frangga-snow.workers.dev`), toko Flowpilot (`tokotelegram.com/toko/flowpilot`), endpoint update GitHub Flowpilot (`masplangga/flowpilot`), public key minisign Flowpilot (`9883364C90076B4B`), dan identifier `com.flowpilot.desktop`.

1. **Prioritas Tinggi (P1 — Terkecil & Aman):** Pindahkan `eslint` ke `devDependencies` (atau hapus jika belum dipakai / ganti ke ESLint 9 flat config), lalu segarkan entri transitif lockfile yang sudah berstatus non-breaking agar sisa peer `@babel/core@7.21.8` / `@babel/traverse@7.21.5` / `less@4.1.3` / `source-map-js` hilang (memangkas `1` Critical + mayoritas High tanpa mengubah API aplikasi).
2. **Prioritas Sedang (P2):** Evaluasi terpisah upgrade teruji `vite` + `@vitejs/plugin-react` (ke `vite 6.x`/`8.x` yang kompatibel dengan Node 20 & `@vitejs/plugin-react`) untuk menghilangkan 2 CVE aktif `vite` + `esbuild` (terutama risiko `launch-editor` UNC NTLMv2 pada dev Windows).
3. **Prioritas Terkait `DESIGN.MD` (P3):** Tentukan apakah `DESIGN.MD` tetap memakai `tailwindcss` v3 (atau v4 / CSS murni); jika bertahan di v3, perbarui sub-dependency lockfile secara aman.

### 2. Analisis Mendalam `reqwest` & Stack HTTP/TLS
Verifikasi `cargo tree -i rustls --locked` dan `cargo tree -i ring --locked` memastikan kedua versi `reqwest` berbagi satu versi **`rustls v0.23.43`**, **`ring v0.17.14`**, **`tokio-rustls v0.26.4`**, **`hyper v1.11.0`**, dan **`hyper-rustls v0.27.9`**. Perbedaan krusialnya ada pada **kepercayaan sertifikat CA**:
- `reqwest 0.12.28` (`license_store.rs`) menggunakan `webpki-roots v1.0.9` (CA bundle statis yang tertanam di binary — tidak mengikuti sertifikat root Windows atau proxy perusahaan jika diperlukan).
- `reqwest 0.13.4` (`tauri-plugin-updater`) menggunakan `rustls-platform-verifier v0.7.0` (mengikuti trust store OS Windows).
- Menyelaraskan `Cargo.toml` ke `reqwest = "0.13"` setelah MSVC siap akan menghapus duplikasi crate HTTP dan menyatukan verifikasi TLS.

### 3. Temuan Aktual vs. Potensi Risiko Rust
- **Temuan Aktual:**

  3. Versi `tauri` (`2.11.5` vs `2.12.7`) dan `tauri-plugin-updater` (`2.10.1` vs `2.14.1`) tertinggal dari patch terbaru (`tauri info`).
