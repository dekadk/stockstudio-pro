## 1. Summary of Changes

Tugas rebranding **C-B-A** telah diselesaikan secara terkendali tanpa menyentuh sistem lisensi, endpoint updater/kunci minisign, CSP, WebView navigation security, implementasi Google Flow, maupun tata letak/arsitektur UI (`v0.3.0`):

1. **Application Identity:** Memperbarui `productName` (`StockStudio Pro`), `identifier` (`com.stockstudiopro.desktop`), nama paket npm (`stockstudio-pro`), Rust crate/binary (`stockstudio-pro` -> `stockstudio-pro.exe`), library Rust (`stockstudio_pro_lib`), versi (`0.2.0`), Windows Credential Manager keyring service (`StockStudioPro`), window title (`StockStudio Pro`), teks hook NSIS, serta metadata workflow `.github/workflows/release.yml`.
2. **Official Logo Integration & Windows Icons:** Menggunakan SVG resmi tanpa modifikasi path/warna ([`src/assets/branding/iconssoren.svg`](file:///e:/2.%20Microstock/TOOL/flowpilot-main/flowpilot-main/src/assets/branding/iconssoren.svg) oranye `#FE9102` dan [`src/assets/branding/iconssputih.svg`](file:///e:/2.%20Microstock/TOOL/flowpilot-main/flowpilot-main/src/assets/branding/iconssputih.svg) putih `#FEFEFE`), menghapus filter CSS `invert(1) brightness(1.8)` agar logo oranye tampil sesuai warna aslinya, menghasilkan `src-tauri/icons/icon.ico` multibit/multisize asli (`16`, `24`, `32`, `48`, `64`, `256`) beserta seluruh aset `src-tauri/icons/*` melalui `npx --no-install tauri icon`, dan menghapus gambar merek Flowpilot yang usang (`public/foursquare.png`, `public/logo-preview.png`).
3. **Fresh Application Profile:** Mengisolasi profil runtime desktop ke `%LOCALAPPDATA%\com.stockstudiopro.desktop` dan key storage frontend ke `stockstudio-profile` / `stockstudio-accounts`, tanpa memigrasi, mengubah, atau menghapus data Flowpilot lama di `%LOCALAPPDATA%\com.flowpilot.desktop`.
4. **UI Branding Copy:** Mengganti seluruh teks merek yang terlihat pengguna dari `Flowpilot` ke `StockStudio Pro` dan event internal `flowpilot-webview-ready` ke `stockstudio-webview-ready`, sambil mempertahankan seluruh integrasi `Google Flow`, navigasi, komponen, dan fungsionalitas inti tetap utuh.
