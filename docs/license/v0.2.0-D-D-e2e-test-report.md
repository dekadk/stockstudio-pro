## 3. Perilaku Online / Offline, Device Limit, & Persistensi

1. **Perilaku Online & Offline Grace:**
   - Saat Worker lokal aktif, `validate_license` memanggil `POST /v1/licenses/validate` menggunakan `Bearer ssact_...` dari Windows Credential Manager (`StockStudioPro / activation-token`), memverifikasi `lease_token` Ed25519 baru, dan memperbarui `clock-anchor` serta `license-state.json`.
   - Saat Worker dimatikan (*network unreachable*), desktop client tidak mengunci pengguna di layar aktivasi; Rust memverifikasi tanda tangan Ed25519 pada `lease_token` tersimpan, memeriksa batas *offline grace* 7 hari dan *clock rollback guard* (toleransi 5 menit), lalu membuka dashboard dalam status `Active (Offline Grace)`.
   - Saat Worker aktif kembali, validasi online berhasil dan indikator status kembali normal (`Active`).
2. **Device Limit & Persistensi:**
   - Aktivasi perangkat pertama mengklaim 1 dari 2 slot secara atomik (`1 / 2 Devices`).
   - Restart aplikasi mempertahankan `device_id` (UUID v4) di Windows Credential Manager (`StockStudioPro / device-id`) sehingga tidak membuat perangkat baru maupun meminta aktivasi ulang.
