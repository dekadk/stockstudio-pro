## 5. Langkah Deployment Berikutnya (`TASK E-C`)

Setelah seluruh persiapan `E-A` dan `E-B` direview, langkah berikutnya untuk mengaktifkan Worker staging adalah:

1. **Deploy Worker ke Cloudflare Staging (`*.workers.dev`):**
   ```powershell
   cd workers/license-api
   npx wrangler deploy --env staging
   ```
2. **Verifikasi Live Health Check Staging:**
   ```powershell
   Invoke-RestMethod -Uri "https://stockstudio-pro-license-api-staging.<subdomain>.workers.dev/v1/health" -Method GET
   ```
   Pastikan `ok = true`, `product_id = com.stockstudiopro.desktop`, `signing_kid = sspro-ed25519-staging-01`, dan `public_key_base64` terisi (44 karakter).
3. **Uji End-to-End Desktop StockStudio Pro terhadap Staging Worker** menggunakan `STOCKSTUDIO_LICENSE_API_URL`, `STOCKSTUDIO_LICENSE_PUBLIC_KEY_BASE64`, dan `STOCKSTUDIO_LICENSE_SIGNING_KID` dari staging.
