## 4. Langkah Berikutnya (`TASK E-B`: Migrasi D1 Remote & Secrets Staging)

Setelah review laporan ini, langkah operasional berikutnya untuk mengaktifkan staging adalah:

1. **Terapkan Migrasi Schema ke D1 Remote Staging (`0001_initial_license_schema.sql`):**
   ```powershell
   cd workers/license-api
   npm run db:migrate:staging
   # ekuivalen: npx wrangler d1 migrations apply DB --env staging --remote
   ```
2. **Buat Pasangan Kunci Ed25519 Khusus Staging (`kid = sspro-ed25519-staging-01`) & Secret Peppers Baru** *(terpisah dari `.dev.vars` lokal)*, lalu unggah ke Cloudflare Secrets:
   ```powershell
   npx wrangler secret put LICENSE_KEY_PEPPER --env staging
   npx wrangler secret put ADMIN_TOKEN_PEPPER --env staging
   npx wrangler secret put IP_HASH_SALT --env staging
   npx wrangler secret put LICENSE_SIGNING_PRIVATE_KEY_JWK --env staging
   npx wrangler secret put LICENSE_SIGNING_PUBLIC_KEY_BASE64 --env staging
   npx wrangler secret put BILLING_WEBHOOK_SECRETS_JSON --env staging
   ```
3. **Seed `signing_keys` dan 1 `super_admin` ke D1 Remote Staging**, kemudian lakukan deployment Worker staging (`npx wrangler deploy --env staging`) dan verifikasi `GET https://stockstudio-pro-license-api-staging.<subdomain>.workers.dev/v1/health`.
