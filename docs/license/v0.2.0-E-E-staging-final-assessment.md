## 1. Ringkasan Arsitektur Staging yang Berjalan

Infrastruktur staging StockStudio Pro License API telah berjalan secara penuh di Cloudflare Edge dan terintegrasi langsung dengan aplikasi desktop StockStudio Pro (Tauri `2.11.5` + Rust + React 18):

- **Cloudflare Worker Staging:** `stockstudio-pro-license-api-staging`
  - **URL Staging:** `https://stockstudio-pro-license-api-staging.dekadk00.workers.dev`
  - **Version ID Terverifikasi:** `b783d204-e089-409f-b76c-6d758d643621`
  - **Cloudflare PoP Terobservasi:** `SIN` (APAC)
  - **Wrangler Version:** `3.114.17`
- **Cloudflare D1 Remote Staging:** `stockstudio-pro-licenses-staging` (`870f9578-82ab-4516-b45f-5300ed3f5e29`, Region `APAC`)
  - **Schema:** 9 tabel dari `migrations/0001_initial_license_schema.sql` (`activations`, `admin_api_keys`, `billing_events`, `billing_subscriptions`, `devices`, `license_events`, `licenses`, `rate_limit_buckets`, `signing_keys`).
  - **Principal & Kunci Aktif:** `1` admin aktif (`super_admin`, prefix `ssadm_01M7XF08DM`), `1` signing key aktif (`kid = sspro-ed25519-staging-01`, `Ed25519`), `5` Cloudflare Secrets (`ADMIN_TOKEN_PEPPER`, `IP_HASH_SALT`, `LICENSE_KEY_PEPPER`, `LICENSE_SIGNING_PRIVATE_KEY_JWK`, `LICENSE_SIGNING_PUBLIC_KEY_BASE64`).
- **Desktop Rust License Client (`src-tauri/src/license_store.rs`):**
  - Menghubungi Worker staging via HTTPS (`reqwest` + `rustls-tls`), memverifikasi tanda tangan Ed25519 `lease_token` menggunakan `ed25519-dalek` v2, dan menyimpan kredensial secara terpisah di Windows Credential Manager (`StockStudioPro`) serta `%LOCALAPPDATA%\com.stockstudiopro.desktop\license-state.json`.
- **Pemisahan Environment (`Development` vs `Staging` vs `Production`):**
  - **Development Lokal:** Tetap terisolasi penuh (`http://127.0.0.1:8787`, `.dev.vars`, `DB --local`, `sspro-ed25519-dev-01`, 1 lisensi uji lokal).
  - **Staging Remote:** Menggunakan Cloudflare Worker, D1 remote, secrets, dan pasangan kunci Ed25519 independen (`sspro-ed25519-staging-01`).
  - **Production:** Belum dibuat dan belum dideploy (menunggu domain resmi, pasangan kunci produksi, dan tahap *Production Preparation*).

## 3. Temuan Operasional Penting dari Fase Staging

1. **Pemblokiran DNS ISP Indonesia terhadap `*.workers.dev` (`E-C`):**
   - ISP lokal (`XL Axiata`, DNS port 53) mengalihkan domain publik `*.workers.dev` ke `blockpage.xlaxiata.id`.
   - **Dampak Wajib untuk Produksi:** Aplikasi produksi **tidak boleh** menggunakan domain `*.workers.dev`. Penggunaan **custom domain resmi** (mis. `license.<domain-stockstudiopro>`) pada Cloudflare Workers adalah syarat mutlak agar pengguna di Indonesia tidak terblokir DNS ISP.
2. **Keamanan Lifecycle & Rotasi Kunci (`E-D1.1`):**
   - Prosedur revokasi + penerbitan pengganti terbukti berjalan cepat dan bersih di D1 staging.

## 4. Batasan Pengujian yang Masih Tersisa (Pekerjaan Lanjutan)

Daftar berikut sengaja tidak diulang pada tahap ini dan dicatat sebagai item verifikasi lanjutan sebelum rilis produksi:
1. Pembuktian batas akhir *offline grace period* selama 7 hari penuh secara live.
2. Pengujian manipulasi *clock rollback* pada jam sistem OS Windows secara live.
3. Pengujian *subscription lifecycle* (`monthly` / `yearly`, renewal, expiration, refund) dengan payment provider nyata.
4. Pengujian *billing webhook* nyata dari payment gateway terpilih.
5. Pengujian *device limit* (`2/2` → `409 DEVICE_LIMIT_REACHED`) menggunakan dua/tiga perangkat fisik nyata.
6. Penyediaan infrastruktur production (Cloudflare Worker, D1 terpisah, custom domain resmi, production secrets, dan Ed25519 signing key produksi).
7. Prosedur pemantauan (*observability/alerting*), backup D1 terjadwal, dan pemulihan insiden (*disaster recovery*) untuk lingkungan production.
